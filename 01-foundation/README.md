# Certification 1: TOGAF Enterprise Architecture Foundation

## Goal

Build accurate vocabulary and a connected mental model of the Architecture Development Method (ADM). Foundation is not about designing a perfect enterprise; it verifies that you understand core concepts and can distinguish closely related terms.

Every theory module links to a matching walkthrough in the [Foundation worked examples](../examples/README.md#foundation-examples). Try each example before reading its solution.

## Completion standard

Complete every activity, explain the ADM without notes, and score at least 80% on the original mock twice on separate days. The real pass threshold and format are listed in [exam facts](../reference/exam-facts.md); a higher practice target creates safety margin.
