# Worked examples library

Theory explains **what** a concept means. These examples show **how to think with it**. Each example is linked from its matching theory module, so you can study in either order.

## Recommended pattern

1. Read the situation and stop at **Try it first**.
2. Write a rough answer without looking at the walkthrough.
3. Compare reasoning, not wording.
4. Complete the variation; changing one fact should sometimes change the best action.
5. Return to the linked theory and summarize the rule in one sentence.

## Example conventions

- **Fact:** given by the scenario and safe to use.
- **Assumption:** plausible but must be validated.
- **Decision:** an authorized choice with consequences.
- **Output:** a useful artifact or update, not paperwork for its own sake.
