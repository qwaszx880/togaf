# Example-writing guide

These instructions apply to `examples/`.

- Begin with a situation a learner can picture before introducing TOGAF terminology.
- Reuse Northstar Outfitters unless a smaller everyday analogy teaches the idea better.
- Show the reasoning between input and result; do not present polished artifacts without explaining choices.
- Separate facts, assumptions, decisions, and outputs.
- End each worked example with a learner variation and a short debrief.
- Link back to the theory module so learners can move in either direction.
