# Documentation contributor guide

## Scope

These instructions apply to the entire repository.

## Writing principles

- Write original explanations; do not copy the TOGAF Standard or exam questions.
- Introduce an acronym before using it and link important terms to `reference/glossary.md`.
- Prefer short paragraphs, descriptive headings, tables, checklists, and concrete examples.
- Use the fictional Northstar Outfitters case study for cross-module continuity.
- Keep exam facts in `reference/exam-facts.md`, with an official source and verification date.
- Every learning module should state outcomes, teach the topic, provide an example, include a hands-on activity, and end with a knowledge check.

## Validation

Run `python3 scripts/check_docs.py` after changing Markdown navigation or links.
