# TOGAF Enterprise Architecture Certification Preparation

An original, hands-on course for the two progressive certifications based on the TOGAF Standard, 10th Edition:

1. **TOGAF Enterprise Architecture Foundation** — understand the language, structure, and purpose of the framework.
2. **TOGAF Enterprise Architecture Practitioner** — apply and analyze the framework in realistic situations.

> The certification names intentionally omit “10”. The Open Group decoupled certification names from standard version numbers. This independent course prepares learners for the bodies of knowledge drawn from the 10th Edition; it is not an official or accredited Open Group course.

## Choose your route

| Starting point | Route through this repository | Typical outcome |
|---|---|---|
| New to TOGAF | [Orientation](00-start-here/README.md) → Foundation → Practitioner | Prepare for Part 1, then Part 2 (or the combined exam) |
| Foundation certified | Orientation refresh → Practitioner | Prepare for Part 2 |
| Experienced architect, new to TOGAF | Diagnostic → weak Foundation modules → Practitioner | Map existing skills to TOGAF concepts |
| TOGAF 9 Certified | Review the official Bridge syllabus first | This course helps, but is not a dedicated Bridge course |

## How to learn, not just read

For every module: **preview → study → retrieve → apply → review**. Read the outcomes, study without highlighting everything, close the page and recall the main ideas, complete the activity, then explain your answer aloud. Use the [progress tracker](00-start-here/progress-tracker.md) and keep an error log.
