# Last-week quick reference

## ADM verbs

**Preliminary** prepare → **A** envision/authorize → **B** business → **C** data/applications → **D** technology → **E** group solutions → **F** prioritize/plan → **G** govern delivery → **H** monitor/change; **Requirements** connect all.

## High-value distinctions

| Do not confuse | Test yourself with |
|---|---|
| Preliminary / Phase A | capability readiness / one cycle’s authorization |
| Phase E / Phase F | packages and route / detailed priority and plan |
| Phase G / Phase H | implementation conformance / ongoing architecture fitness |
| Viewpoint / view | recipe / representation |
| Deliverable / artifact | formal package / descriptive content |
| ABB / SBB | needed capability / realized component |
| Continuum / Repository | classification / storage and organization |
| Roadmap / Migration Plan | directional timeline / actionable plan |

## Scenario triage

Ask: What outcome? Which stakeholders/concerns? What has already happened? Which ADM moment? What constraint matters? Does the choice preserve evidence, order, governance, proportionality, and traceability?

## Reference-navigation drill

Before Part 2, practice finding—not memorizing—the sections for stakeholder management, each ADM phase, gap analysis, risk/security, content, and governance. Write keywords you would search. Time ten lookups; target under 45 seconds each without browsing aimlessly.

## Final 48 hours

Review the error log and distinctions, do light retrieval, confirm logistics, and sleep. Do not introduce a new unofficial question bank or attempt to memorize prose.
