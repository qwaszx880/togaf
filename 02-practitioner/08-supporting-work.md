# P8 — Supporting ADM work

## Outcomes

Integrate risk, security, readiness, business information, and capability-based planning into—not beside—the ADM.

> **See it in practice:** Connect [value stream, capability, information, organization, readiness, and risk](../examples/practitioner/06-supporting-techniques.md) into one decision chain.

## Integrated practices

| Practice | Use in ADM work | Failure mode |
|---|---|---|
| Risk and security | Identify concerns/controls early; update risks each phase; assure implementation | Security review only at the end |
| Readiness | Assess capacity, culture, skills, sponsorship; create actions | Calling resistance “communication failure” |
| Business scenarios | Discover problem, environment, actors, objectives, and requirements | Beginning with a preferred solution |
| Capability-based planning | Connect strategic outcomes to stable “what we can do” capabilities and increments | Confusing capability with department/application |
| Value streams | Show stakeholder value across stages | Modeling internal process detail only |
| Information mapping | Clarify business information and flows | Jumping to database schemas |
| Organization mapping | Expose actors, ownership, locations, and relationships | Assuming org chart equals operating model |

Risk has an owner, likelihood/impact, response, and residual exposure. Controls become traceable requirements and architecture elements. Security concerns and threat changes remain active throughout the lifecycle.

## Exercise

For Northstar, map the “collect an accurate order” value stream to capabilities. Identify two information concepts, accountable organizational actors, two risks, controls, residual exposure, and readiness actions.

## Check

**Scenario:** A capability map duplicates the organization chart. Best improvement? **Answer:** describe stable business abilities needed for outcomes independent of current reporting structures, then map organization ownership separately.
