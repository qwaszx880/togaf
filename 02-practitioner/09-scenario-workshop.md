# P9 — Scenario workshop and original mock

> **See it in practice:** Work through [all four passes and rank every answer](../examples/practitioner/07-scenario-reasoning.md) before attempting the scenarios below.

## Outcomes

Extract decisive scenario facts, locate the applicable ADM work, rank all answer choices, and use the open-book reference efficiently.

## Four-pass method

1. **Read the ask first:** identify phase/topic and requested action.
2. **Mark facts:** outcomes, constraints, stakeholders, maturity, work already completed.
3. **Rank principles:** eliminate bypasses, premature detail, wrong sequence, and absolutes.
4. **Compare remaining choices with BEST:** select the most complete contextual response—not the longest.

Because the live Part 2 uses gradient scoring, practice ranking all four options: best, second, third, worst. Budget roughly 11 minutes per live scenario, reserving time to revisit marked items. See [exam facts](../reference/exam-facts.md).

## Scenario 1 — Urgent federation

Northstar’s regions select technology independently. The board funds a shared reservation capability in nine months. Regional leaders fear central control; stock definitions differ. What should the lead architect do first?

- **A.** Select one region’s platform as the standard and mandate migration.
- **B.** Establish the vision and scoped outcomes with stakeholders, agree federated decision rights and common information principles, then plan iterative domain work.
- **C.** Fully document every regional application before speaking to sponsors.
- **D.** Let every region implement independently and integrate after launch.

**Ranking:** B best; C second because Baseline knowledge helps but is disproportionate and stakeholder-late; A third because it creates direction but prematurely selects a solution and bypasses concerns; D worst because it worsens semantic/integration risk. (Depending on extra facts, middle rankings can change; document evidence.)

## Scenario 2 — Delivery deviation

A delivery team proves the target integration pattern cannot meet a legally mandated response time. The deadline is fixed. What response is strongest?

- **A.** Enforce the architecture because it was approved.
- **B.** Let the team silently use any alternative.
- **C.** Record the evidence and requirement impact, assess compliant alternatives with relevant stakeholders, route a time-bounded decision through governance, and update controlled architecture/risks.
- **D.** Cancel the entire program immediately.

**Ranking:** C best; A second (preserves governance but ignores new evidence); D third (addresses compliance but is disproportionate without analysis); B worst (no traceability or authority).

## Scenario 3 — Roadmap

Four packages compete: data cleanup enables all others; customer app has highest visible value; store training is needed before pilot; observability lowers rollout risk. What should Phase F do?

- **A.** Fund only the customer app because it has highest direct value.
- **B.** Prioritize using value, dependencies, readiness, cost, and risk; define transition states and gain portfolio agreement.
- **C.** Start all packages immediately regardless of capacity.
- **D.** Defer planning to each vendor.

**Ranking:** B best; A second; C third; D worst. B is the only option that treats migration as an integrated portfolio decision.

## Readiness rubric

You are ready when you can, without notes: identify the relevant ADM stage, quote scenario evidence in your rationale, rank rather than merely pick, explain why tempting choices are incomplete, and find supporting material quickly in the exam reference. Redo these scenarios after one week and reverse one fact to see how ranking changes.
